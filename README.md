# Command Center

A personal productivity dashboard: daily brief, tasks, replies, habits, working set and a weekly review.

## Status

Design phase. The app has not been scaffolded yet.

## Design

UI designs live in `design/` (the source of the canvas at https://claude.ai/artifact/1DUdad1m3RYN15j932Dagj):

| File | Screen |
| --- | --- |
| `design/Main.dc.html` | Home: today |
| `design/Tasks.dc.html` | Tasks |
| `design/Review.dc.html` | Weekly review |
| `design/Palette.dc.html` | Ctrl+K command palette |

Design rules: dark theme with a single accent colour; every card ends in an action;
no hero KPI cards, emoji, gradients, glass effects, nested cards, or pure black/white.
